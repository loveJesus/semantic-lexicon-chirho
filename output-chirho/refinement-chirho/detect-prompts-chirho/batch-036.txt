# Sense Refinement Detection — Batch 036

You are a biblical lexicographer reviewing sense entries for a Hebrew/Aramaic/Greek lexicon.
Each entry below is a single "sense" that was produced by clustering translation signatures 
and then merging with an LLM. Some senses may have been OVER-LUMPED — they contain genuinely 
distinct meanings that should be separate senses.

## Your Task

For each sense, determine if it should be SPLIT into multiple senses. Look for:
- Literal vs. figurative/metaphorical uses lumped together
- Concrete vs. abstract meanings combined
- Multiple distinct referents (e.g., "father" = biological parent + patron/advisor + originator)
- Physical vs. spiritual/theological uses merged
- Different syntactic frames producing different meanings

## Output Format

Return a JSON array. For senses that need NO splitting, omit them entirely.
For senses that SHOULD be split, include an entry like:

```json
[
  {
    "senseIdChirho": 79287,
    "lemmaIdChirho": "H0001",
    "currentLabelChirho": "father, immediate male parent",
    "splitProposalChirho": [
      {
        "newLabelChirho": "biological/legal father",
        "criteriaChirho": "Direct parent-child relationship, possessive constructions with specific person"
      },
      {
        "newLabelChirho": "metaphorical father (patron, advisor, protector)",
        "criteriaChirho": "Title of respect for prophets, advisors, or authority figures; 'father to Pharaoh' type usage"
      }
    ],
    "confidenceChirho": "high",
    "reasoningChirho": "Description explicitly mentions 'title of respect or metaphorical originator' alongside biological father"
  }
]
```

Only propose splits where you have MEDIUM or HIGH confidence. Do NOT split function words (articles, 
prepositions, particles, conjunctions) unless there is a genuinely distinct semantic sense (not just 
syntactic variation). Proper nouns generally should NOT be split.

If NO senses in this batch need splitting, return an empty array: []
